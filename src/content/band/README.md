# Band sections

Each `.md` file here is one section on the home page, shown in `order`.

```markdown
---
title: "Our Sound"
order: 3
---

Write the section here. Normal Markdown works: **bold**, *italics*, [links](https://example.com).
```

- To reorder sections, change the `order` numbers.
- To add a section, add a new file with the next `order` number.
- To remove one, delete its file.
